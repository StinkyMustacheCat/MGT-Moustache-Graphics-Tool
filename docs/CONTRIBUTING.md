# Contribuir

Mantener 60 FPS de exportación, compatibilidad v1/v2 y funcionamiento local sin red para editar/exportar. No introducir autoguardado ni ejecución automática de archivos al importarlos.

Cambios de código propio se reciben bajo GPL-3.0-or-later; documentación bajo CC BY-SA4.0 según LICENSING.md. Solo aportar material sobre el que se tenga autorización suficiente.

Para presets, declarar autor y licencia en metadata y conservar los avisos necesarios. CC0 es la preferencia para nuevas aportaciones originales cuando su titular lo acepte, no un requisito aplicado retroactivamente a archivos MIT u otras licencias. Importar o guardar no equivale a cambiar la licencia.

Al reportar un fallo: versión, pasos, resultado esperado y observado. Ajustes > Copiar diagnóstico evita incluir contenido del proyecto. Copiar error es distinto y puede incluir fragmentos del código: revisar antes de compartir. Adjuntar una composición mínima sin información privada cuando sea necesario. Aún no se ha configurado una URL definitiva de incidencias.

Pruebas mínimas antes de proponer una versión: cargar JSON anterior, cambiar controles, guardar/recargar, fallo y recuperación, exportar60FPS, importación sin ejecutar y limpieza limitada a archivos propios. Evitar publicar archivos personales o runtimes sin revisar sus licencias y fuentes correspondientes.
